# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately through GitHub Private Vulnerability Reporting:

https://github.com/kaarude/ferry/security/advisories/new

Include:

- A description of the vulnerability and where it lives in the codebase.
- Steps to reproduce or a minimal proof of concept.
- Potential impact and any suggested fix if you have one.

## Scope

This policy covers the Ferry source code and official releases from this repository. That includes anything a Discord user could do through Ferry to the linked GitHub repo, such as abusing the bot's token, triggering unwanted notifications, or manipulating the duplicate check. Report problems in discord.js, the GitHub API, or the Anthropic API to their maintainers.

## What to expect

We aim to acknowledge new reports within 7 days and work with you on a fix before any public disclosure. Please give us reasonable time to investigate and patch the issue before sharing details publicly.
